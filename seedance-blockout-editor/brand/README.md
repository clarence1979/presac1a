| File | What |
|---|---|
| `tein-logo-dark.svg` | mark + wordmark for dark backgrounds (ink #f4f4f6, Signal block #1F18C0) |
| `tein-logo-light.svg` | mark + wordmark for light backgrounds (ink #16161a) |
| `tein-mark.svg` | the block mark alone |
| `tein-logo-dark@2x.png`, `tein-logo-light@2x.png` | 512 px wide exports |
| `tein-logo.js` | the same logo as inline SVG for the app (`teinMark`, `teinWord`, `teinLogo`) |

The wordmark is vector outlines, not text: it cannot be selected, copied or restyled with a font. Do not recolour, rearrange, round or stretch the blocks; the blue Signal block stays #1F18C0.
